# Skills

[Knowledge-Hub](../../README.md) / [.ai](../AI.md) / skills

Agent skills, one folder per skill, each with a `SKILL.md`. [`AGENTS.md`](../../AGENTS.md) says when each one applies.

## Business notes

- [setup-owner](setup-owner/SKILL.md) — interview the user and create or complete `people/Me.md`, the vault owner profile
- [vault-conventions](vault-conventions/SKILL.md) — rules for every business note (source of truth)
- [capture-input](capture-input/SKILL.md) — text, file, or record split into meeting, decision, task, person, project, and standalone notes
- [extract-tasks](extract-tasks/SKILL.md) — commitments to task lines; complete, cancel, reassign
- [update-entities](update-entities/SKILL.md) — create and update people and project notes
- [log-decision](log-decision/SKILL.md) — decision records and superseding
- [query-knowledge](query-knowledge/SKILL.md) — answer questions from the vault with citations
- [weekly-review](weekly-review/SKILL.md) — weekly review in `journal/`

## Study notes

- [md-note-structure](md-note-structure/SKILL.md) — structure rules for study notes (source of truth)
- [new-note](new-note/SKILL.md) — create a study note and register it in its topic index
