# Inbox

[Knowledge-Hub](../README.md) / Inbox

Raw input waiting to be filed into notes: pasted conversations, transcripts, chat exports, and email threads. Files here are not notes and are not validated. Name them `YYYY-MM-DD_<source>_<slug>.md` so they never collide with note names.

## Folders

- [_processed](_processed/Processed.md) — raw input that has already been filed
- `audio/` — recordings, kept out of git
